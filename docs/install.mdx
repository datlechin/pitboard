## What you need

| System | The command line | The app |
| --- | --- | --- |
| macOS | Apple silicon or Intel | macOS 14 or later, on Apple silicon or Intel |
| Windows | Windows 11 24H2 or later, or Windows Server 2025, on x64 or ARM64 | The same as the command line |
| Linux | x86_64 or aarch64, on any distribution | None |

The app includes the command line, so install one or the other. On an older Windows, Pitboard [changes nothing](/troubleshooting/refused-changes#pitboard-changes-nothing-on-this-version-of-windows).

You also need Claude Code, OpenAI's Codex CLI or Claude Desktop, signed in to one of your accounts. Claude Desktop accounts need macOS. Read [Before you enrol a Codex account](/guides/codex#before-you-enrol-a-codex-account) or [Before you add a Claude Desktop account](/guides/claude-desktop#before-you-add-a-claude-desktop-account) first.

Pitboard for Windows is in beta, and its files are not signed. It was run with real Claude Code logins on 18 October 2026, with Claude Code 2.1.302. Codex sign-ins and switches on Windows have not been measured.

On Linux, Pitboard builds and passes its tests, but has not been run with real logins.

## Install the app

<Tabs>
  <Tab title="macOS">
    Download the app from [Download Pitboard](https://usepitboard.com/download), then move `Pitboard.app` to your Applications folder before you open it. Until then, macOS runs it from a temporary copy, and the app cannot turn on [daily renewal](/guides/renewal) or link its command line.

    Or install it with Homebrew. The `pitboard-app` cask also puts the app's command line on your `PATH`, with its man page and completions:

    ```sh
    brew install --cask datlechin/tap/pitboard-app
    ```

    Without the cask, put the app's command line on your `PATH` from **Settings** > **Advanced**: click **Install Command Line Tool**, then enter an administrator's password when macOS asks. It then updates with the app. [Command line](/reference/settings#command-line) says when the button shows. You can also run `/Applications/Pitboard.app/Contents/Helpers/pitboard`.
  </Tab>
  <Tab title="Windows">
    <Steps>
      <Step title="Download the installer">
        From [Download Pitboard](https://usepitboard.com/download#windows), download the ARM64 installer for a PC with an Arm processor, or the x64 one for any other. **Settings** > **System** > **About** names the processor under **System type**. The x64 installer also runs on an Arm PC, under emulation.
      </Step>
      <Step title="Open the installer">
        If Windows shows **Windows protected your PC**, select **More info**, then **Run anyway**. What Microsoft Edge shows as it downloads the installer has not been measured. If Smart App Control blocks it, see [Smart App Control blocks Pitboard](/troubleshooting#smart-app-control-blocks-pitboard).

        It installs Pitboard for your Windows account alone, with no administrator prompt. It puts the command line on your `PATH`, where a terminal opened after the install finds it.
      </Step>
      <Step title="Open Pitboard">
        Open **Pitboard** from Start. Its icon starts among the hidden icons of the notification area: drag it onto the taskbar to keep it in sight.
      </Step>
    </Steps>
  </Tab>
</Tabs>

Linux has no app: install the command line.

## Install with the script

On macOS and Linux, the install script installs the command line:

```sh
curl -fsSL https://usepitboard.com/install.sh | sh
```

[The install script](/install/script) says where it puts each file, what it needs and how to choose another folder.

## Install with Homebrew

On macOS and Linux, the `pitboard` cask installs the command line, with its man page and completions:

```sh
brew install datlechin/tap/pitboard
```

It and the `pitboard-app` cask both put `pitboard` on your `PATH`, so Homebrew installs only one of the two.

## Install the command line on Windows

The app's installer puts the command line on your `PATH`. For the command line alone, install it from its zip:

<Steps>
  <Step title="Download the zip">
    From [Download Pitboard](https://usepitboard.com/download#windows), download the ARM64 zip for a PC with an Arm processor, or the x64 one for any other.
  </Step>
  <Step title="Copy the command line out of it">
    The zip holds one folder, named like the zip. Copy `pitboard.exe` from it to a folder of its own, such as `.local\bin` in your user folder.

    You need not unblock it: `pitboard.exe` marked as downloaded from the internet ran from a terminal with no prompt, measured on 18 October 2026.
  </Step>
  <Step title="Add the folder to your Path">
    In Start, search for `environment variables`, then select **Edit environment variables for your account**. Under your user variables, select **Path**, then **Edit**. Select **New**, enter the folder, then select **OK** in both dialogs.

    In a terminal opened after that, check that it runs:

    ```sh
    pitboard --version
    ```
  </Step>
</Steps>

With cargo-binstall, name the release's version, as [Cargo](/install/other-ways#cargo) says.

## Install inside WSL

Claude Code and Codex installed inside WSL keep logins of their own, and Pitboard for Windows does not switch them. To switch them, install the command line inside WSL as on Linux, with [the install script](#install-with-the-script) or [Homebrew](#install-with-homebrew). There, `pitboard doctor` says on its `WSL` line what it switches.

Where Codex's home inside WSL is a folder on a Windows drive, such as `/mnt/c/Users/me/.codex`, Codex on Windows may use the same login. A switch on either side then changes it for both, so enrol and switch that Codex from one side only.

[Other ways to install](/install/other-ways) covers Cargo, release files and building the app from source.

## Update Pitboard

| Installed with | To update |
| --- | --- |
| The install script | Run the script again, with the same `PITBOARD_INSTALL_DIR` if you set one. |
| The `pitboard` cask | `brew upgrade pitboard` |
| The app on macOS, from its cask or a release file | It updates itself. |
| The app on Windows | It updates itself to each full release. To install a later beta, open its installer. |
| Cargo, a release file or a build of your own | As [Other ways to install](/install/other-ways) says for each. |

[Updates](/reference/settings#updates) lists the app's update settings. `brew upgrade --greedy` also upgrades the `pitboard-app` cask.

Keep a command line installed apart from the app at the app's version. An older one refuses a file the app wrote, with `was written by a newer Pitboard`.
