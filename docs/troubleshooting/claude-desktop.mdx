[Troubleshooting](/troubleshooting) covers the checks to run first and how to report a problem.

## Claude is open

A Claude Desktop change stops with `app_open`, and changes nothing, while Claude is open:

```text
error: Claude is open, and Pitboard changes its login only while it is closed. Quit Claude with Command-Q, then run this again. Nothing has changed.
```

Closing its window leaves it running.

If the error says Claude has quit and names a part of it still running, such as `ShipIt (pid 812)`, wait until it ends. Or quit it in Activity Monitor. Then try again.

## Claude is waiting to reset its data

A Claude Desktop change stops with `login_folder_unknown`, and changes nothing:

```text
error: Claude's data folder is waiting for Reset App Data, which deletes what it holds the next time Claude opens, so Pitboard moves no Claude Desktop login. Open Claude, quit it with Command-Q, then run this again. Nothing has changed.
```

Claude's **Reset App Data** did not finish. Open Claude to let it finish, which signs Claude out, then quit it and try again. Your parked accounts stay in Pitboard.

## A parked Claude Desktop account opens signed out

After a switch to a Claude Desktop account, Claude shows its sign-in page: the parked login no longer works. `pitboard` may already have said `sign-in may have lapsed`.

Quit Claude, then [sign in to the account again](/guides/claude-desktop#sign-in-again), so Pitboard records the new login.

## Account data in a form Pitboard has not read

`pitboard doctor` warns on its `Claude data folder layout` line, and Pitboard starts no Claude Desktop move, refusing with `login_folder_unknown`:

```text
error: Claude's data folder holds `Cookies-wal`, a part of the account's data this Pitboard has not read, so Pitboard moves no Claude Desktop login. Update Pitboard, or report it at https://github.com/datlechin/pitboard/issues if no release reads it yet. Nothing has changed.
```

A build of Claude keeps part of a store Pitboard moves where Pitboard has no record of it, so a move would split the store. [Update Pitboard](/install#update-pitboard). If no release reads it yet, [report a problem](/troubleshooting#report-a-problem) with the name. Claude Code and Codex switches go ahead.
