Without Pitboard, changing account in Claude Code or OpenAI's Codex CLI means signing out and signing in again in a browser.

<Frame>
  <img src="/images/menu.png" alt="The Pitboard menu, listing Claude Code and Codex accounts, with a check mark on each one in use and, under each account's name, its usage or that it needs signing in again" width="300" />
</Frame>

Pitboard keeps the login of each account you are not using, called a [parked login](/concepts/switching#parked-logins). A switch puts the chosen account's parked login where the tool reads it. Your history, settings and projects stay where they are.

[Open Claude Code sessions](/concepts/switching#open-sessions) follow a switch within about 33 seconds, with no restart. Anything that runs Codex keeps the old account until it starts again. [What happens to open sessions](/guides/switch#what-happens-to-open-sessions) lists what to restart.

Pitboard finishes or undoes an [interrupted switch](/concepts/switching#interrupted-switches) before it makes any other change.

Pitboard can also [switch Claude Code by itself](/guides/automatic-switching) before the account in use runs out. It is off until you turn it on.

The menu bar app gives each account its own [window on claude.ai or chatgpt.com](/guides/account-windows), where you sign in as that account.

Pitboard has no server of its own and no telemetry. It sends each login only to the service that issued it. [What leaves your machine](/security#what-leaves-your-machine) lists every request.

## What it works with

Pitboard works with Claude Code, and with Codex signed in with ChatGPT. For Codex, read [Before you enrol a Codex account](/guides/codex#before-you-enrol-a-codex-account) first.

The command line runs on macOS and Linux. The menu bar app runs on macOS 14 or later and includes the command line. [What you need](/install#what-you-need) gives the architectures and how far each system is tested.

[Tools and sign-ins Pitboard does not support](/concepts/limits#tools-and-sign-ins-pitboard-does-not-support) lists what it leaves out. [Is this allowed](/concepts/limits#is-this-allowed) covers the services' terms.

To check a release file before you run it, see [Verify a download](/install/verify).
