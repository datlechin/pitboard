Pitboard switches Claude Code, OpenAI's Codex CLI and Claude Desktop between your own accounts, and shows how much each account has left.

<Frame>
  <img src="/images/menu.png" alt="The Pitboard menu, listing Claude Code and Codex accounts, with a check mark on each one in use and, under each account's name, its usage or that it needs signing in again" width="300" />
</Frame>

If you have more than one Claude or ChatGPT subscription, switching accounts in either tool means signing out and signing in again in a browser.

Pitboard keeps the login of each account you are not using, called a parked login. A switch puts the chosen account's parked login where the tool reads it.

Your conversation history, settings and projects stay where they are. Open Claude Code sessions pick up the switch within about 33 seconds, and a running `codex` needs a restart.

The menu bar app also gives each account a window on claude.ai or chatgpt.com, where you sign in as that account. See [Use each account's site](/guides/account-windows).

## What it works with

Pitboard works with Claude Code, and with Codex signed in with a ChatGPT account. For what Codex needs, see [Use Pitboard with Codex](/guides/codex#before-you-enrol-a-codex-account).

On macOS, Pitboard also switches Claude Desktop, Anthropic's app, while Claude is quit. The menu bar app quits Claude for a switch and opens it again. See [Use Pitboard with Claude Desktop](/guides/claude-desktop).

Pitboard is a command line for macOS and Linux, and a menu bar app for macOS 14 or later that includes the command line. For requirements and how far Linux is tested, see [Install Pitboard](/install#what-you-need).

Gemini CLI is not supported. For other unsupported tools and sign-ins, see [What Pitboard will not do](/concepts/limits#tools-and-sign-ins-pitboard-does-not-support).
