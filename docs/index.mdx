Without Pitboard, changing account in Claude Code, OpenAI's Codex CLI or Claude Desktop means signing out and signing in again.

Pitboard keeps the login of each account you are not using, called a [parked login](/concepts/switching#parked-logins). A switch puts the chosen account's parked login where Claude Code, Codex or Claude Desktop reads it. Your history, settings and projects stay where they are.

[Pitboard and other ways to use several accounts](/concepts/several-accounts) compares this with a config folder per account and with other tools.

[Open Claude Code sessions](/concepts/open-sessions) follow a switch within about 33 seconds, with no restart. Anything that runs Codex keeps the old account until it starts again. Claude Desktop switches only while Claude is closed, and Claude opens signed in to the account switched to. [What happens to open sessions](/guides/switch#what-happens-to-open-sessions) says what each tool does.

Pitboard finishes or undoes an [interrupted switch](/concepts/switching#interrupted-switches) before it changes that tool's login again.

While the app is open, it [notifies you](/guides/switch#get-a-notification-before-a-limit-runs-out) once a limit of the account in use reaches 95%. Pitboard can also [switch Claude Code by itself](/guides/automatic-switching), from the app or a background service, once you turn it on.

The app gives each Claude Code and Codex account its own [window on claude.ai or chatgpt.com](/guides/account-windows), where you sign in as that account.

Pitboard has no server of its own and no telemetry. It sends each login only to the service that issued it. [What leaves your machine](/security#what-leaves-your-machine) lists every request.

## Where it runs

| Part | Systems |
| --- | --- |
| The command line | macOS, Windows and Linux |
| The app, which includes the command line | macOS and Windows |

The app runs from the menu bar on macOS, and from its icon in the notification area on Windows. [What you need](/install#what-you-need) gives the versions, the architectures and how far each system is tested.
