[Install Pitboard](/install) gives the app, the install script and Homebrew, and how to update each way.

## Cargo

[cargo-binstall](https://github.com/cargo-bins/cargo-binstall) downloads Pitboard's own release build for your machine. Building from source needs Rust 1.91 or later and a C compiler.

```sh
cargo binstall pitboard
cargo install --locked pitboard
```

Neither installs the man page or the completions. [`pitboard manpage`](/reference/integration-commands#manpage) and [`pitboard completions`](/reference/integration-commands#completions) print them. To update, run the same command again.

On Windows, name the version. Without one, Cargo installs the most recent full release, and a Windows build of a release before 1.0.0 changes nothing: it refuses with [`windows_not_released`](/reference/errors#windows). [Download Pitboard](https://usepitboard.com/download#other-ways) gives both commands with the Windows release's version.

On Windows, building from source needs Rust's MSVC toolchain on x64 or ARM64, and clang as well on ARM64.

## A release file

[Download Pitboard](https://usepitboard.com/download#release-files) lists each file of the most recent release and what it is for. To check a file before you open it, follow [Verify a download](/install/verify).

Each tarball, for macOS or Linux, holds `pitboard`, `pitboard.1`, `completions/`, `LICENSE`, `NOTICE` and `README.md`. Copy `pitboard` to a directory on your `PATH`.

On Windows, each zip holds `pitboard.exe`, `completions/pitboard.ps1`, `completions/pitboard.bash`, `LICENSE`, `NOTICE` and `README.md`, with no man page. [Install the command line on Windows](/install#install-the-command-line-on-windows) shows how to put `pitboard.exe` on your `PATH`.

To update, replace the files with the next release's.

The macOS app's zip and the Windows installers install the app, as [Install the app](/install#install-the-app) says.

## Build the app

In a clone of [Pitboard's repository](https://github.com/datlechin/pitboard), `./apps/macos/scripts/build-app.sh` writes `apps/macos/build/Pitboard.app`. Copy it to your Applications folder. [The macOS app](https://github.com/datlechin/pitboard/blob/main/CONTRIBUTING.md#the-macos-app) lists what it needs.

The Windows app builds only on Windows, from `apps/windows`, as [The Windows app](https://github.com/datlechin/pitboard/blob/main/CONTRIBUTING.md#the-windows-app) says.

An app you build has no updater. Build it again to update it.

On macOS, an app built without `SIGN_IDENTITY`, a Developer ID identity, shows no accounts in its widgets and control.
