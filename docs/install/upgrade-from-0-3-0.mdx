---

Up to 0.3.0, `datlechin/tap` had a `pitboard` formula for the command line and a `pitboard` cask for the app. From 0.4.0, the `pitboard` cask is the command line, and the `pitboard-app` cask is the app with the command line inside it.

## From the old formula

`brew update` warns that it did not install the cask that replaces the formula. Pitboard stays at the version you have. The two commands `brew update` prints leave `pitboard` running the formula's copy.

Remove the formula, then install the cask:

```sh
brew uninstall --formula pitboard
brew install datlechin/tap/pitboard
```

## From the old app cask

`brew update` replaces the app with the command line. The app's settings and your accounts in `~/.pitboard` stay.

<Warning>
  Leave `--zap` out when you remove the old app cask. Its zap moves `~/.pitboard` to the Trash. That folder is the only index of your accounts and their parked logins. Homebrew runs the zap of the cask as you installed it, even after the tap changes.
</Warning>

To get the app back, run these in order, before or after `brew update`:

```sh
# Remove the old app, or the command line that replaced it
brew uninstall --cask pitboard
# Remove the formula the old app depended on, if it is there
brew uninstall --formula --force pitboard
# Install the app and the command line inside it
brew install --cask datlechin/tap/pitboard-app
```

## If you downloaded the app from a release

The app updates itself as before. From 0.4.0, each update brings the command line inside the app. To run it in a terminal, see [Put the bundled command line on your PATH](/install#put-the-bundled-command-line-on-your-path).

## If daily renewal was on

In an app up to 0.3.0, the daily renewal schedule ran the app itself and renewed nothing. When that schedule starts an app from 0.4.0 or later, the app renews through the command line inside it. Opening the app once points the schedule at that command line.

A schedule that runs a `pitboard` that is gone stays broken. On Linux, that includes one turned on with the old formula, which ran the copy inside the formula's folder.

To check yours and fix it, see [Daily renewal stopped working](/troubleshooting#daily-renewal-stopped-working).
