---
title: "Quickstart"
description: "Install Pitboard, add two Claude Code accounts, switch between them and see what each has left."
---

You need Claude Code signed in to one of your accounts. If it is not, run `claude` and sign in.

<Warning>
  Add accounts only through Pitboard, never with Claude Code's `/login`. It replaces the login in use without Pitboard parking it, so that account needs a browser sign-in again.
</Warning>

## In the app

<Tabs>
  <Tab title="macOS">
    <Steps>
      <Step title="Install">
        Download the app from [Download Pitboard](https://usepitboard.com/download), move `Pitboard.app` to your Applications folder, then open it. The first time, it opens the Pitboard window.
      </Step>
      <Step title="Name the account you are signed in to">
        In the **Accounts** pane, click **Name** in the tip **Give this account a name**. Keep the name the dialog suggests, or enter another such as `personal`, then click **Save**.
      </Step>
      <Step title="Add a second account">
        Click **Add Account** in the tip **Add a second account**. Enter a name such as `work`, then click **Sign In**. Sign in as your second account in the browser that opens. If a **Code** field appears, paste the code the page gives you, then click **Submit Code**.
      </Step>
      <Step title="Switch">
        Click Pitboard's item in the menu bar, then choose `work`. Under each account, the menu shows how much of each limit it has used, such as **5-hour 12%, weekly 40%**.
      </Step>
    </Steps>
  </Tab>
  <Tab title="Windows">
    <Steps>
      <Step title="Install">
        Download the installer from [Download Pitboard](https://usepitboard.com/download#windows) and open it, as [Install the app](/install#install-the-app) shows. Open **Pitboard** from Start: it opens the Pitboard window. Its icon starts among the hidden icons of the notification area.
      </Step>
      <Step title="Name the account you are signed in to">
        In the **Accounts** pane, select **Name** in the tip **Give this account a name**. Keep the name the dialog suggests, or enter another such as `personal`, then select **Save**.
      </Step>
      <Step title="Add a second account">
        Select **Add account** in the tip **Add a second account**. Enter a name such as `work`, then select **Sign in**. Sign in as your second account in the browser that opens. If a **Code** field appears, paste the code the page gives you, then select **Submit code**.
      </Step>
      <Step title="Switch">
        Right-click Pitboard's icon in the notification area, then select `work`. Point to an account to see how much of each limit it has used, such as **5-hour 12%, weekly 40%**.
      </Step>
    </Steps>
  </Tab>
</Tabs>

## On the command line

<Steps>
  <Step title="Install">
    On macOS and Linux, install the command line with the script:

    ```sh
    curl -fsSL https://usepitboard.com/install.sh | sh
    ```

    If it says `~/.local/bin` is not on your `PATH`, do as it says.

    On Windows, the app puts the command line on your `PATH`. For the command line alone, follow [Install the command line on Windows](/install#install-the-command-line-on-windows).
  </Step>
  <Step title="Enrol the account you are signed in to">
    Pitboard knows each account by a [label](/reference/commands#labels), a short name you choose. Enrol the account in use as `personal`:

    ```sh
    pitboard enroll personal
    ```

    ```text
    Enrolled personal (me@example.com), the account signed in now.
    Add another without signing out of it: pitboard enroll <label> --sign-in
    ```
  </Step>
  <Step title="Add a second account">
    ```sh
    pitboard enroll work --sign-in
    ```

    ```text
    Opening Claude Code's sign-in. Sign in as the account to add; the account in use now stays signed in.
    ```

    Sign in as your second account in the browser that opens. If Claude Code asks for a code, paste in the one the browser shows.

    ```text
    Enrolled work (me@company.com). Switch to it with: pitboard use work
    ```
  </Step>
  <Step title="Switch">
    ```sh
    pitboard use work
    ```

    ```text
    Switched to work; personal is parked.
    Claude Code sessions already running follow within 33 seconds.
    ```

    `personal`'s login stays [parked](/concepts/switching#parked-logins) until you switch back with `pitboard use personal`.
  </Step>
  <Step title="See what each account has left">
    ```sh
    pitboard
    ```

    ```text
    ● work      me@company.com  Max 20x  signed in
        5h    █░░░│░░░░░   12%  resets in 3h 00m  28% under pace
        week  ████░░│░░░   40%  resets in 2d 4h   29% under pace

    ○ personal  me@example.com  Max 20x  ready · good for 26d 4h
        5h    ██████░│░░   59%  resets in 1h 10m  18% under pace
        week  █│█████░░░   73%  resets in 5d 18h  55% over pace
    ```

    - `●` marks the account in use.
    - `ready` means you can switch to the account.
    - `good for 26d 4h` is how long its parked login lasts.
    - `5h` and `week` are the five-hour and weekly limits.
    - `│` marks where the bar would reach at an even [pace](/concepts/usage#pace).

    For every line Pitboard can show, see [Account status](/reference/account-status).
  </Step>
</Steps>

To add accounts of OpenAI's Codex CLI or Claude Desktop, see [Use Pitboard with Codex](/guides/codex) and [Use Pitboard with Claude Desktop](/guides/claude-desktop).
