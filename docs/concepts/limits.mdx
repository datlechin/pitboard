---
title: "What Pitboard will not do"
description: "What Pitboard leaves alone, what a switch costs you, and which tools and sign-ins it does not support."
---

Pitboard is for one person with several accounts of their own in Claude Code or OpenAI's Codex CLI.

## Rules

- Pitboard switches by itself only while [automatic switching](/guides/automatic-switching) is on in the app or `pitboard watch` is running.
- It switches only Claude Code by itself. [What a switch costs you](#what-a-switch-costs-you) says why.
- Pitboard never sees a tool's requests, so it never proxies or pools them.
- It decides an automatic switch from usage it has already read, never from a refused or rate-limited request. [Keep the numbers fresh](/guides/automatic-switching#keep-the-numbers-fresh) says how old that usage can be.
- Pitboard never renews the login in use. The tool renews it, and a renewal spends the refresh token a running session may still hold.
- [`pitboard stow`](/reference/recovery-commands#stow) is the one exception. It can renew an expired login in a login file behind the keychain, under Claude Code's refresh lock.
- Pitboard never copies a parked login to another machine. Once one machine renews it, the other machine's copy is spent.
- Each machine signs in to each account itself. [The Pitboard directory came from another computer](/troubleshooting/recovery#the-pitboard-directory-came-from-another-computer) covers a copied `~/.pitboard`.

## What a switch costs you

Open Claude Code sessions keep the account they leave for up to about 33 seconds. Everything that runs Codex, the ChatGPT app included, keeps its account until it starts again. [Open sessions](/concepts/switching#open-sessions) explains both.

An automatic switch would miss the `codex` session it was meant to keep going, so Pitboard never switches Codex by itself. [What happens to open sessions](/guides/switch#what-happens-to-open-sessions) lists what to restart.

## Is this allowed

Pitboard moves only logins you already hold, between its own store and the place each tool reads them. It has no way to share an account between people.

Anthropic's and OpenAI's terms decide whether you may use several subscriptions this way. [Anthropic terms](/security#anthropic-terms) quotes what Anthropic says about third-party apps and logins.

## Tools and sign-ins Pitboard does not support

- Gemini CLI. Since 18 June 2026, Google no longer offers Gemini CLI's **Login with Google** to individual, Google AI Pro and Google AI Ultra accounts. Google says so in [Gemini Code Assist consumer accounts](https://developers.google.com/gemini-code-assist/docs/deprecations/code-assist-individuals).
- Codex signed in with an API key rather than ChatGPT.
- Codex keeping its login anywhere but `auth.json`, its file store. [Before you enrol a Codex account](/guides/codex#before-you-enrol-a-codex-account) shows how to check.
- Google sign-in and passkeys in an account's window. [Sign in](/guides/account-windows#sign-in) gives the ways that work.
- Windows. A Windows build answers only `--version`, `--help`, `completions` and `manpage`, and refuses the rest with [`windows_not_released`](/reference/errors#windows).
- Claude Code with `CLAUDE_CODE_CUSTOM_OAUTH_URL` set. Its login then sits under a name Pitboard does not read. [Custom OAuth endpoint](/reference/files#custom-oauth-endpoint) lists what Pitboard refuses.
- Claude Code set to use `ANTHROPIC_API_KEY`, `ANTHROPIC_AUTH_TOKEN`, `CLAUDE_CODE_OAUTH_TOKEN`, `apiKeyHelper` or a third-party provider. Its sessions ignore the login Pitboard switches. [Variables that override the login](/reference/files#variables-that-override-the-login) lists them all.
