---
title: "Switch accounts"
description: "Switch Claude Code or Codex to another enrolled account from the menu bar, the Pitboard window or the command line."
---

A switch puts another account's [parked login](/concepts/switching#parked-logins) in use for Claude Code or OpenAI's Codex CLI, and parks the login the tool had.

## Switch to another account

<Tabs>
  <Tab title="App">
    Click Pitboard's item in the menu bar, then choose the account.

    In the Pitboard window, click **Use** in the account's row, double-click the row, or select it and press Return.
  </Tab>
  <Tab title="Command line">
    Run `pitboard use` with the account's label, such as `work` or `codex/work`.

    ```sh
    pitboard use work
    ```

    ```text
    Switched to work; personal is parked.
    Claude Code sessions already running follow within 33 seconds.
    ```

    [Labels](/reference/commands#labels) says how Pitboard matches a label.
  </Tab>
</Tabs>

## What Pitboard checks first

Pitboard moves nothing until these hold:

- The tool is signed in to an enrolled account.
- The account you switch to has a parked login.
- Anthropic or OpenAI confirms over the network that the parked login works and is that account's.

An expired or refused parked login needs a sign-in: see [Sign in to an account again](/guides/sign-in-again). [Error and warning codes](/reference/errors) lists every code.

`pitboard use` with the account in use moves no login. It only corrects Claude Code's config when that names another account.

## What happens to open sessions

Open Claude Code sessions follow a switch within about 33 seconds, with no restart. In the app, the Pitboard window counts down those seconds. [Open sessions](/concepts/switching#open-sessions) says why.

On macOS, while a login file sits behind the keychain, open sessions follow only at their next renewal or restart. Put it away with `pitboard stow` or **Put Away** in the Pitboard window: see [Claude Code over SSH uses another account](/troubleshooting#claude-code-over-ssh-uses-another-account).

Codex never follows a switch: see [Open sessions](/concepts/switching#open-sessions). Restart what runs it:

| What runs Codex | What to do |
| --- | --- |
| A `codex` session | Quit it and start it again. |
| The ChatGPT app, OpenAI's desktop app | Quit it with Command-Q, not by closing its windows, and open it again. |
| Codex's background app server | Run `codex app-server daemon restart`. |
| Codex in an editor | Run **Developer: Reload Window** in each window that uses Codex. |

Read in the ChatGPT app 26.928.31416 and Codex 0.159.3. The editor row is not measured.

After a Codex switch, Pitboard lists which of these still run. If it cannot read the process list, it warns with `sessions_unknown`.

<Warning>
  Do not sign out in anything that ran Codex before the switch. That includes `/logout` in a `codex` session and **Log Out** in the ChatGPT app. Each holds the parked login, and signing out revokes it at OpenAI. See [Why Codex logins are moved, not copied](/concepts/switching#why-codex-logins-are-moved-not-copied).

  If you did, Control-click the old account in the Pitboard window and choose **Sign In Again**, or run `pitboard enroll codex/personal --sign-in`.
</Warning>

### Switch while the ChatGPT app is open

While the ChatGPT app is open, a Codex switch in the app asks first. **Quit ChatGPT and Switch** quits it, switches, then opens it again. **Cancel** switches nothing.

If the ChatGPT app has not quit within 30 seconds, nothing changes. The command line never quits an app.

## When an account runs out

When the account in use runs out of a limit, the app offers another account of the same tool, under 100% in every limit. [Which account it switches to](/guides/automatic-switching#which-account-it-switches-to) gives the rule.

The offer comes as a notification titled **work has no 5-hour limit left**, which says **personal has 58% of its own left.** Its **Switch** button switches to `personal`.

Pitboard's menu and window show it as **Switch to personal**, with or without notifications.

Each offer comes once per limit and reset, even across restarts. If no account has room, it offers nothing. The command line offers no switch.

Pitboard can also switch Claude Code by itself: see [Switch before an account runs out](/guides/automatic-switching).
