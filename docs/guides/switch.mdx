---
title: "Switch accounts"
description: "Switch a tool to another enrolled account from the app's menu, the Pitboard window or the command line."
---

A switch puts another account's [parked login](/concepts/switching#parked-logins) in use for Claude Code, OpenAI's Codex CLI or Claude Desktop, and parks the login the tool had. Where nothing is signed in to the tool, as on a new computer, it puts the account's login in use and parks nothing.

## Switch to another account

<Tabs>
  <Tab title="macOS">
    Click Pitboard's item in the menu bar, then choose the account.

    In the Pitboard window, click **Use** in the account's row, double-click the row, or select it and press Return.
  </Tab>
  <Tab title="Windows">
    Right-click Pitboard's icon in the notification area, then select the account.

    In the Pitboard window, select **Use** in the account's row, double-click the row, or select it and press Enter.
  </Tab>
</Tabs>

On the command line, run `pitboard use` with the account's label, such as `work`, `codex/work` or, on macOS, `desktop/work`. [Labels](/reference/commands#labels) says how Pitboard matches a label.

```sh
pitboard use work
```

```text
Switched to work; personal is parked.
Claude Code sessions already running follow within 33 seconds.
```

Where nothing was signed in, the first line names the tool instead: `Switched Claude Code to work.`

## What Pitboard checks first

Pitboard moves nothing until the account has a parked login and the tool is signed in to an enrolled account, or to nothing. For Claude Code and Codex, Anthropic or OpenAI first confirms over the network that the parked login works and is that account's. A Claude Desktop switch needs Claude closed instead.

An expired or refused parked login needs a [sign-in again](/guides/sign-in-again). [Error and warning codes](/reference/errors) lists every refusal. `pitboard use` with the account in use moves no login: it only corrects Claude Code's config when that names another account.

## Replace a login Anthropic refuses

When Anthropic refuses for good the login Claude Code has in use, that login no longer works and cannot be parked. A switch asks before it puts the other account's login in its place. Replacing the refused login loses nothing.

In the app, click **Replace** in the **Replace Claude Code's Login?** alert. On Windows, select **Replace** in the **Replace Claude Code's login?** dialog.

`pitboard use` asks the same at a terminal, ending with `Put work's login in its place? [y/N]`. Without a terminal, or with `--json`, it refuses with `live_login_refused` until you add `--yes`:

```sh
pitboard use work --yes
```

## What happens to open sessions

| Tool | After a switch |
| --- | --- |
| Claude Code | Open sessions follow within about 33 seconds, with no restart. The Pitboard window counts down. |
| Codex | Nothing that runs Codex follows. Restart each, as [Restart what runs Codex](/guides/codex#restart-what-runs-codex) says. |
| Claude Desktop | Claude opens signed in to the account switched to. |

[How open sessions follow a switch](/concepts/open-sessions) says why, and what was measured on each system.

On macOS, while a login file sits behind the keychain, open Claude Code sessions follow only at their next renewal or restart. On Windows, the same holds for a login file behind Credential Manager. Put it away as [Claude Code over SSH uses another account](/troubleshooting#claude-code-over-ssh-uses-another-account) says.

## Get a notification before a limit runs out

While the app is open, it notifies you once a limit of the account in use reaches a share you choose, 95% at first. Where another account of that tool is under the share in every limit, the notification's **Switch** button switches to it.

<Tabs>
  <Tab title="macOS">
    In **Settings** > **Limits**, under **Before an account runs out**, choose **Notify Me** in **When a limit reaches**. Set the share in the field or with the stepper beside it. **Do Nothing** turns the notification off.
  </Tab>
  <Tab title="Windows">
    Right-click Pitboard's icon in the notification area and select **Settings**. Under **Limits**, select **Notify me** in **When a limit reaches**, then expand it and set the share in **Share of a limit**. **Do nothing** turns the notification off.
  </Tab>
</Tabs>

The command line posts no notification. [Notifications](/reference/mac-app#notifications) gives its words and when it comes.

## When an account runs out

When the account in use runs out of a limit, the app offers another account of the same tool, under 100% in every limit, by the rules in [Which account it switches to](/reference/automatic-switching#which-account-it-switches-to). If no account has room, it offers nothing. The command line offers no switch.

The offer is **Switch to personal** in Pitboard's menu and window.

Pitboard can also [switch Claude Code by itself](/guides/automatic-switching) before an account runs out.
