---
title: "Add and manage accounts"
description: "Enrol the account each tool is signed in to, add more through a sign-in, and rename or forget them."
---

Pitboard switches only between accounts you enrol. Each one gets a label, the name you switch to it by.

Claude Desktop accounts are added inside Claude, on macOS, as [Use Pitboard with Claude Desktop](/guides/claude-desktop) shows.

## Add the account you are signed in to

<Tabs>
  <Tab title="macOS">
    In the **Accounts** pane of the Pitboard window, click **Name** in the tip **Give this account a name**. Keep the name the dialog suggests, or enter another such as `personal`, then click **Save**.
  </Tab>
  <Tab title="Windows">
    In the **Accounts** pane of the Pitboard window, select **Name** in the tip **Give this account a name**. Keep the name the dialog suggests, or enter another such as `personal`, then select **Save**.
  </Tab>
</Tabs>

Until a Codex account is enrolled, the tip **Use Pitboard with Codex** adds Codex's login instead: see [Add Codex accounts](/guides/codex#add-codex-accounts). On the command line:

```sh
pitboard enroll personal          # Claude Code
pitboard enroll codex/personal    # Codex
```

```text
Enrolled personal (me@example.com), the account signed in now.
Add another without signing out of it: pitboard enroll <label> --sign-in
```

## Add another account

Pitboard runs the tool's own sign-in in a private directory, so the account in use stays signed in.

<Tabs>
  <Tab title="macOS">
    <Steps>
      <Step title="Open the dialog">
        Click Pitboard's item in the menu bar, then choose **Add Account**. Choose **Claude Code** or **Codex** in the **Tool** pop-up menu.
      </Step>
      <Step title="Name the account">
        Enter a name such as `work`, then click **Sign In**.
      </Step>
      <Step title="Sign in">
        Sign in as the account you are adding, in the browser that opens. If a **Code** field appears, paste the code the page gives you, then click **Submit Code**. To sign in from another browser, click **Copy Link** and paste the address there. If no browser opens, click **Open**.
      </Step>
    </Steps>
  </Tab>
  <Tab title="Windows">
    <Steps>
      <Step title="Open the dialog">
        Right-click Pitboard's icon in the notification area, then select **Add account**, or press Ctrl+N in the Pitboard window. Under **Tool**, select **Claude Code** or **Codex**.
      </Step>
      <Step title="Name the account">
        Enter a name such as `work`, then select **Sign in**.
      </Step>
      <Step title="Sign in">
        Sign in as the account you are adding, in the browser that opens. If a **Code** field appears, paste the code the page gives you, then select **Submit code**. To sign in from another browser, select **Copy link** and paste the address there. If no browser opens, select **Open**.
      </Step>
    </Steps>
  </Tab>
</Tabs>

If the dialog says Pitboard cannot find the tool, see [Pitboard cannot find a tool](/troubleshooting/accounts#pitboard-cannot-find-a-tool). On the command line, sign in when your browser opens, and paste the code the browser shows if Claude Code asks for one.

```sh
pitboard enroll work --sign-in          # Claude Code
pitboard enroll codex/work --sign-in    # Codex
```

```text
Enrolled work (me@company.com). Switch to it with: pitboard use work
```

Where nothing is signed in to the tool, as on a new computer, [switch to the account](/guides/switch) to put its login in use.

Each organisation your Anthropic account belongs to is a separate account, as are your personal ChatGPT plan and each workspace you belong to. Enrol each under its own label, and sign in to that organisation or workspace in the browser.

<Warning>
  Do not add an account with Claude Code's `/login` or with `codex login`. Each replaces the login in use without Pitboard parking it first, so the account that was in use needs a browser sign-in. `codex login` also revokes the login it replaces: see [Why Codex logins are moved, not copied](/concepts/switching#why-codex-logins-are-moved-not-copied).
</Warning>

## Choose a label

On the command line, a label names its tool: `work` for Claude Code, `codex/work` for Codex and, on macOS, `desktop/work` for Claude Desktop. In the app, choose the tool and enter the name alone. [Labels](/reference/commands#labels) gives the rules.

## Rename an account

Renaming changes only the label. The account keeps its parked login, and its [account window](/guides/account-windows) stays signed in.

<Tabs>
  <Tab title="macOS">
    In the **Accounts** pane, Control-click the account, then choose **Rename**, or select it and choose **Account** > **Rename**. Enter the new name, then click **Rename**.
  </Tab>
  <Tab title="Windows">
    In the **Accounts** pane, right-click the account and select **Rename**, or select it and press F2. Enter the new name, then select **Rename**.
  </Tab>
</Tabs>

On the command line:

```sh
pitboard rename wrong right
```

## Forget an account

To forget the account in use, switch to another account first.

Forgetting an account deletes its parked login on this computer, with everything its [account window](/guides/account-windows) keeps, or a Claude Desktop account's folders set aside.

<Tabs>
  <Tab title="macOS">
    In the **Accounts** pane, select the account and press Delete or Command-Delete, or Control-click it and choose **Forget**. Click **Forget** to confirm.
  </Tab>
  <Tab title="Windows">
    In the **Accounts** pane, select the account and press Delete, or right-click it and select **Forget**. Select **Forget** to confirm.
  </Tab>
</Tabs>

On the command line, `pitboard forget old` asks first, and `--yes` skips the question.

Pitboard does not revoke the login it deletes. That login stays valid until it expires: see [SECURITY.md](https://github.com/datlechin/pitboard/blob/main/SECURITY.md#out-of-scope).
