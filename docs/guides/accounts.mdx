---
title: "Add and manage accounts"
description: "Enrol the account you are signed in to, sign in to more, and rename or forget them."
---

pitboard switches only between accounts you enrol. Enrol the account each tool is signed in to, then sign in to the others through pitboard.

Before you start, run Claude Code once and sign in. For OpenAI's Codex CLI, see [Before you enrol a Codex account](/guides/codex#before-you-enrol-a-codex-account) first.

## Add the account you are signed in to

<Tabs>
  <Tab title="App">
    The pitboard window opens by itself the first time you open the app. Later, click pitboard's item in the menu bar, then choose **Open pitboard**.

    1. In the **Accounts** pane, find the tip **Give this account a name** and click **Name**.
    2. In **Name This Account**, enter a name such as `personal`, then click **Save**. The account appears under that name.

    For Codex, this tip appears only once a Codex account is enrolled, so add the first with **Add Account**, as in the next section.
  </Tab>
  <Tab title="Command line">
    ```sh
    pitboard enroll personal          # Claude Code
    pitboard enroll codex/personal    # Codex
    ```

    ```text
    Enrolled personal (me@example.com), the account signed in now.
    Add another without signing out of it: pitboard enroll <label> --sign-in
    ```
  </Tab>
</Tabs>

When you switch away from an account, pitboard parks its login: it keeps the login so you can switch back. Enrolling this account parks nothing.

Enrolling a Claude Code account needs the network: pitboard asks Anthropic whose login it is.

## Add another account

pitboard runs the tool's own sign-in in a separate directory, so the account in use stays signed in.

<Tabs>
  <Tab title="App">
    1. In pitboard's menu, choose **Add Account**. The **Add Account** dialog opens.
    2. If the dialog has a **Tool** pop-up menu, click it, then choose **Claude Code** or **Codex**. For which tools it offers, see [Dialogs and alerts](/reference/app#dialogs-and-alerts).
    3. Enter a name such as `work`, then click **Sign In**. Your browser opens.
    4. Sign in as the account you are adding. The dialog closes and the account appears in the list.

    If the browser does not open, click **Open Sign-In Page**. If a **Code** field appears, paste the code your browser shows, then click **Submit Code**.
  </Tab>
  <Tab title="Command line">
    ```sh
    pitboard enroll work --sign-in          # Claude Code
    pitboard enroll codex/work --sign-in    # Codex
    ```

    Your browser opens. Sign in as the account you are adding. pitboard then prints:

    ```text
    Enrolled work (me@company.com). Switch to it with: pitboard use work
    ```
  </Tab>
</Tabs>

If the browser signs you in as an account already enrolled, pitboard refuses and names its label. For what `--sign-in` runs, see [Account commands](/reference/account-commands#enroll).

<Warning>
  Do not add an account with Claude Code's `/login` or with `codex login`. Both replace the login in use without pitboard parking it, so the account that was in use needs a browser sign-in again. `codex login` also revokes the login it replaces.
</Warning>

## Choose a label

A label is the one-word name pitboard knows an account by, such as `work`. When you enrol an account or sign in to it again, `work` means Claude Code and `codex/work` means Codex. In the app, you choose the tool and enter the name without `codex/`.

In `pitboard use`, `pitboard forget` and `pitboard rename`, `work` alone is enough while only one tool has a `work` account. Otherwise, write `claude/work` or `codex/work`. For the full rules, see [Labels](/reference/commands#labels).

## Rename an account

Renaming changes only the label. An account's [claude.ai window](/guides/claude-web) stays signed in.

<Tabs>
  <Tab title="App">
    In the **Accounts** pane, Control-click the account, then choose **Rename**. Change the name, then click **Rename**.
  </Tab>
  <Tab title="Command line">
    ```sh
    pitboard rename wrong right
    ```

    ```text
    Renamed wrong to right (me@company.com).
    ```

    A rename stays inside its tool: `pitboard rename codex/work job` gives `codex/job`.
  </Tab>
</Tabs>

## Forget an account

Forgetting an account deletes its parked login, so adding it again needs a browser sign-in. For a Claude Code account, it also deletes what the account's [claude.ai window](/guides/claude-web) keeps, its sign-in included. To forget the account in use, switch to another account first.

<Tabs>
  <Tab title="App">
    In the **Accounts** pane, select the account and press Delete, or Control-click it and choose **Forget**. Click **Forget** to confirm.
  </Tab>
  <Tab title="Command line">
    ```sh
    pitboard forget old
    ```

    pitboard asks first:

    ```text
    Forget old and delete its parked login? Adding it again needs a browser sign-in. [y/N]
    ```

    Type `y`, then press Return. pitboard prints:

    ```text
    Forgot old (old@example.com).
    ```

    To skip the question, add `--yes`.
  </Tab>
</Tabs>

The app deletes the claude.ai window's data at once when you forget in the app, and at its next read when you forget with `pitboard forget`.

Forgetting does not revoke the parked login, so it stays valid until it expires. For what that means, see [Security and privacy](/security#what-pitboard-protects-against).
