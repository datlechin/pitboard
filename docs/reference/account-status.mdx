---
title: "Account status"
description: "What each mark and line under an account means, in the app's menu and window and in `pitboard status`."
---

[Check what each account has left](/guides/usage) shows where each appears. The App column gives the menu bar app's words.

On Windows, the app writes the same words in sentence case, such as **In use** and **Sign in again**. Pitboard's menu marks the account in use with a dot, and the line the menu bar app shows under an account, such as **5-hour 59%, weekly 73%**, is that item's tooltip.

| App | Command line | Meaning |
| --- | --- | --- |
| A check mark in the menu, **In Use** in the window | `●` and `signed in`, and `○` on the others | The tool is using this account. |
| **Read 2h 05m ago, with Claude closed** in the window | `signed in · read 2h 05m ago` | When Pitboard last read the Claude Desktop account in use, during a change with Claude closed. |
| **work · Max 20x** in the menu, a **Max 20x** tag beside the name in the window | `Max 20x` after the address | The plan the account's login says it is on. |
| **5-hour 59%, weekly 73%** in the menu, a bar per limit in the window | `5h`, `week` and a bar per limit | How much of each limit the account has used. A limit for one model adds the model's name. |
| **No usage read** in the menu | `Pitboard reads no usage for Claude Desktop`, once before its accounts | Pitboard reads no usage for a Claude Desktop account: see [What Pitboard does not do for Claude Desktop](/concepts/claude-desktop#what-pitboard-does-not-do-for-claude-desktop). |
| A green, orange or red bar | A green, yellow or red bar and percentage | Under 70%, from 70% and from 90% used. |
| **resetting now** in the window | `resetting now` | The reset time has passed. The figure is the last one measured until the next reading. |
| A red or green mark across a bar, and **55% over pace** or **18% under pace** | `│` in a bar, and `55% over pace` or `18% under pace` | The mark is where an even [pace](/concepts/usage#pace) would be when the numbers were measured. Red: faster than that. Green: slower. `on pace`, with no mark: within 5 points of it. |
| **weekly 73% (runs out in 11h 05m)** in the menu, and a note in the window | `weekly limit runs out in 11h 05m at this pace` | For the account in use, the limit that runs out first at its pace, and when. Under a minute, it reads **about to run out**. |
| **5-hour used up until 22:12** in the menu, or **5-hour used up** once that time has passed | `100%` in red | The account has used all of the limit until it resets. |
| **Parked login good for 26 more days** in the window | `ready · good for 26d 4h` | You can switch to the Claude Code account. Its [parked login](/concepts/switching#parked-logins) lasts that long. |
| No note in the window | `ready` | You can switch to the Codex account. Pitboard knows no expiry for a Codex login. |
| **Its sign-in may lapse in 25 days** in the window | `ready · sign-in may lapse in 25d 3h` | You can switch to the Claude Desktop account. [What Pitboard does not do for Claude Desktop](/concepts/claude-desktop#what-pitboard-does-not-do-for-claude-desktop) says how far to trust the date. |
| **Parked login good for 2 more days** in the window | `ready · expires in 2d 3h`, then a command | The parked login expires within 3 days. [Renew now](/guides/renewal#renew-now). |
| **Its sign-in may have lapsed** in the window | `ready · sign-in may have lapsed`, then a command | The date has passed. If Claude asks you to sign in after a switch, [sign in again](/guides/claude-desktop#sign-in-again). |
| **Needs signing in again** in the menu, **Sign In Again** in the window | `login expired` or `nothing parked`, then a command | Pitboard holds no parked login it can use for the account. [Sign in to an account again](/guides/sign-in-again). |
| **Needs signing in again** in the menu, with **Its parked login is no longer accepted; sign in again** in the window | `ready`, and `its parked login is no longer accepted; sign in again` under the account | Anthropic or OpenAI refused the parked login. [Sign in to an account again](/guides/sign-in-again). |
| **Needs signing in again** in the menu, with the reason in the window | `login replaced outside Pitboard`, then a command | A sign-in outside Pitboard replaced the account's only login. See [An account reads `login replaced outside Pitboard`](/troubleshooting#an-account-reads-login-replaced-outside-pitboard). |
| **Login Pitboard can't use**, or a line such as **Claude Code's login could not be read; run `pitboard doctor`** | `login could not be read`, beside an account or `account unknown` | Pitboard could not read the tool's login. Beside an account, that login may be the account's. Run `pitboard doctor`. |
| **Login Pitboard can't use**, with **Claude Code's login is not one Pitboard can park or switch** | `account unknown` and `login cannot be switched` | The tool is signed in with a login Pitboard cannot park or switch, such as an API key. Run `pitboard doctor`. |
| **Login Pitboard can't identify**, with **Pitboard could not tell which account Claude Code's login is** and the reason | `account unknown` and `account could not be identified` | Anthropic could not be asked, or would not say, which account the login is. The reason says which. |
| **Not named yet** in the menu, the tip **Give this account a name** in the window | `signed in · not enrolled: pitboard enroll <label>` | The tool is signed in to an account Pitboard has not enrolled. [Add the account you are signed in to](/guides/accounts#add-the-account-you-are-signed-in-to). |
| **Switching** in the menu, a progress indicator in the window | None | A switch to the account is running. |
| The email address as the line in the menu, no bars in the window | `no usage known yet`, or `no usage known` and a reason | Pitboard has no reading of the account. [Stale codes](/reference/errors#stale-codes) explains each reason. |

With [`CLAUDE_CONFIG_DIR`](/reference/environment-variables) set, a line such as `for the credential slot Claude Code-credentials-1a2b3c4d` follows the Claude Code accounts. It names the item in the keychain, or in Credential Manager on Windows, that `signed in` refers to.
