The menu bar app runs on macOS 14 or later. [The app on Windows](/reference/windows-app) has its own page.

The app calls the same core as the command line, not `pitboard`, so both see the same accounts, [parked logins](/concepts/switching#parked-logins) and log.

While any of its windows is open, Pitboard also has a Dock icon, a place in the Command-Tab switcher and its own menus. Its windows are the Pitboard window, Settings, each [account's window](/reference/account-windows#account-windows) and the [**Open Link** window](/reference/account-windows#open-link-window).

The first time the app runs, it opens the Pitboard window. Opening Pitboard from Finder or Spotlight with no window open does the same. The Dock icon's menu lists the items that open account windows, then **Open Pitboard**.

Once more than one tool has accounts, the menu and the **Accounts** pane head each tool's accounts with its name, in the order Claude Code, Codex, Claude Desktop. Notices, notifications, the second-account tip and the question before **Forget** then name the tool, as in **Switched Codex to work** and **Add a second Codex account**.

## Menu bar item

Pitboard's item in the menu bar shows the Pitboard mark, the account in use and how much of one limit it has used, such as **work 42%**. [Menu bar shows](/reference/settings#menu-bar-shows) can leave out the label, or the label and the percentage.

| Part | Rule |
| --- | --- |
| Label | The label of the account in use, or **unnamed** when it is not enrolled. Past 12 characters, it is cut to 11 and an ellipsis. |
| Percentage | The fullest limit, as a whole percentage. A limit for one model counts only when there is no other. When Anthropic marks some limits active, only those count. |
| Which account, with several tools | The enrolled account in use closest to running out. An account with no reading counts as the least used, and a Claude Desktop account never has one. |
| A tie between tools | Goes to the tool listed first: Claude Code, then Codex, then Claude Desktop. |

Before the first read, and while no tool is signed in, the item shows the symbol alone. Until the account has a reading, it shows the label alone.

While [the menu](#menu) opens on something that needs attention, the mark has a dot at its bottom right, and VoiceOver ends the item with **needs attention**.

## Menu

Clicking Pitboard's item opens its menu: what needs attention, then the accounts, then the commands. What needs attention comes in this order:

1. **Claude Code isn't installed**, while the app finds none of `claude`, `codex` and Claude's data folder, and no tool has a login or an account.
2. **Switch to personal**, once the account in use runs out of a limit and `personal` has room.
3. **Finish Adding**, **Finish Signing In** and **Put work Back**, while an add or a sign-in again to Claude Desktop is left halfway.
4. The title of a notice in the [Accounts pane](#accounts-pane) with an orange or red symbol and no switch button, or a count such as **2 things to look at**.
5. **Install Pitboard 0.10.1**, once a copy from a release finds an update.

A check mark shows the account in use in each tool. [Account status](/reference/account-status) explains the line under each account.

| Choosing | Does |
| --- | --- |
| An account you can switch to | Switches to it. |
| An account marked **Needs signing in again** | Opens **Sign In to work Again**. |
| The account in use, marked **Not named yet** | Opens **Name This Account**. |
| The account in use, when enrolled | Nothing. |

While a switch runs, every item that would switch is dimmed. **Refresh** reads every account's usage again, even one read moments ago.

## Window

The Pitboard window's sidebar holds three panes: **Accounts**, **Activity** and **This Mac**. It opens on the pane you last showed.

### Accounts pane

The **Accounts** pane lists notices, then at most one setup tip, then the accounts by tool.

Under each account, notes say, in this order: why it cannot be used, why its numbers are old or when Pitboard last read it, which limit runs out first, how long its parked login lasts, and where its [warm-up](/guides/warm-up) stands while it is on. Only the account in use shows which limit runs out first. A bar's tooltip says what an even pace would have used so far.

The setup tip is the first of these that applies. **Not Now** stops it, for that tool alone where the tip names one.

| Setup tip | Shown when |
| --- | --- |
| **Give this account a name** | A tool is signed in to an account Pitboard has not enrolled. |
| **Add a second account** | Claude Code's or Codex's only enrolled account is the one in use. |
| **Add a second Claude Desktop account** | Claude Desktop's only enrolled account is the one in use. |
| **Use Pitboard with Codex** | Codex is installed and no Codex account is enrolled. It reads which account Codex is signed in to only once you click **Add Codex Account**. |
| **Open Pitboard at login** | macOS does not open Pitboard at login. |
| **Switch before a limit runs out** | Claude Code has two enrolled accounts, and nothing was chosen in [When a limit reaches](/reference/settings#when-a-limit-reaches). |

Notices, most pressing first:

| Notice | Shown when |
| --- | --- |
| **An interrupted switch is waiting** | A switch stopped partway, and Pitboard cannot yet tell whether it finished. Where a Claude Desktop move waits too, it says so and stands in for **An interrupted move is waiting**. |
| **Couldn't read usage** | The last read failed. |
| **work has no 5-hour limit left** | The account in use ran out of a limit, and another account of its tool has room. |
| **Switched to work** | The app finished a switch, or a sign-in inside Claude put another account in use. One with nothing under its title goes once its countdown ends. |
| **work has a new login** | A sign-in in the app gave the account in use a new login. |
| **Adding a Claude Desktop account isn't finished**, **Signing in to home again isn't finished** | An add or a sign-in again inside Claude was left halfway with `work` parked for it. It stays across relaunches. |
| **Claude Code's config names another account** | The config names another account than the stored login's. **Update Claude Code's Config** writes the account in use into the config and moves no login. |
| **A login file is left behind the keychain** | `~/.claude/.credentials.json` sits behind the keychain. **Put Away** does what [`pitboard stow`](/reference/recovery-commands#stow) does. |
| **An interrupted move is waiting** | A Claude Desktop move was interrupted, and its record waits. **Give Up** shows once a Claude Desktop change from the app could not settle the move. |
| **The account in use is not confirmed**, on a Claude Desktop account | Claude's settings have named another account, or nobody, since Pitboard last read Claude. |
| Another warning's title | A read or a change warned. [Warning codes](/reference/errors#warning-codes) lists each title. |
| **Gave up on the interrupted switch**, **Gave up on the interrupted move**, **Put away the login left in a file** | You gave up, or **Put Away** finished. Its lines say what became of each login. |

### Activity pane

The **Activity** pane lists the last 500 changes in Pitboard's log, newest first, from the app and the command line. Its **Change** column names the verb [`pitboard log`](/reference/maintenance-commands#log) records:

| Change | Verb |
| --- | --- |
| **Switch** | `use` |
| **Automatic switch** | `auto-switch` |
| **Automatic switch not made** | `auto-stay` |
| **Enrol** | `enroll` |
| **Login in use changed** | `in-use` |
| **Put away a login left in a file** | `stow` |
| **Give up on a switch** | `abandon` |
| **Park for a sign-in** | `park` |
| **Warm-up** | `warm-up` |
| **Warm-up turned on**, **Warm-up turned off** | `warm-on`, `warm-off` |
| **Warm-up hours changed** | `warm-range` |

Any other verb starts with a capital letter, as `rename` reads **Rename**. **Result** gives an outcome's code in words, such as **Parked login expired** for `parked_login_expired`. **Asked By** reads **Unknown** for a change logged before Pitboard recorded who asked.

### This Mac pane

The **This Mac** pane runs the checks of [`pitboard doctor`](/reference/maintenance-commands#doctor) each time you show it, with doctor's summary line over them.

## Accounts and dialogs

Control-clicking an account in the **Accounts** pane opens its shortcut menu. The **Account** menu in the menu bar offers the same items for the account selected there. The shortcut menu leaves out an item that cannot be chosen, and the **Account** menu dims it.

**Warm Up Now** cannot be chosen while the account's five-hour period runs, while it is held back, while a warm-up runs or while nothing can be warmed up here.

Dialogs open over the **Accounts** pane. A dialog whose action fails stays open with what you entered, and says why until you change the name or the tool.

- **Add Account** offers every tool Pitboard handles on this Mac and starts on the first it finds, by `claude`, `codex` or Claude's data folder. For a tool it cannot find, it links how to install it.
- **Name This Account** starts with a name from the email address that no other account of the tool has: the domain's first word for a work address, such as `acme` for `dana@acme.io`, or the part before the `@` for one at a mail service such as Gmail.
- In a Claude Code or Codex sign-in, **Copy Link** copies the sign-in page's address for another browser or browser profile.

A Claude Desktop add or sign-in again offers the button that fits what Pitboard last read:

| Button | Shown when | What it does |
| --- | --- | --- |
| **Add Account** | No Claude Desktop account is enrolled. | Records the account Claude is signed in to under the name. |
| **Park work** | `work` is in use. | Parks `work`, which leaves Claude signed out, then waits for a sign-in inside Claude. |
| **Start Sign-In** | Claude is signed out. | Waits for a sign-in inside Claude. |
| **Add the Account Claude Shows**, or **Record as home** in a sign-in again | An add waits, or Pitboard cannot identify the login Claude holds. | Records the account Claude is signed in to. |
| **Put work Back** | `work` is parked for the sign-in. | Stops waiting and switches back to `work`. |
| **Later** | `work` is parked for the sign-in. | Stops waiting and leaves `work` parked, with a notice that says so. |

Once Claude quits signed in, Pitboard records the account, closes the dialog and says what it did in a notice. It does not open Claude again.

### Quitting Claude or the ChatGPT app

Pitboard asks before it quits Claude for a Claude Desktop change, or the ChatGPT app for a Codex switch. **Cancel** changes nothing. It then asks the app to quit as Command-Q does, and waits up to 30 seconds.

If the app has not quit, Pitboard changes nothing. If part of it still runs after it quit, Pitboard changes nothing and opens it again. Otherwise it makes the change and opens the app again.

## Notifications

| Title | Posted | Body | Button | Clicking the notification |
| --- | --- | --- | --- | --- |
| **work has used 96% of its 5-hour limit**, or **work has no 5-hour limit left** from 100% | With **Notify Me** chosen, when a limit of the account in use reaches the share in [When a limit reaches](/reference/settings#when-a-limit-reaches). With **Switch Automatically**, for Codex only. Once for each limit and reset, even across restarts. | **personal has 58% of its own left.**, or **seat has no such limit.** for an account without that limit. With no account to switch to, **Resets in 1h 05m.** | **Switch**, which switches to `personal`, where another account of its tool is under the share in every limit | Opens **Accounts** |
| **Switched Claude Code to personal** | After each switch the app makes by itself. | **work has used 96% of its 5-hour limit. Sessions already running follow within 33 seconds.** | None | Opens **Accounts** |
| **Claude Code wasn't switched** | When a limit of the account in use reaches the share in **When a limit reaches**, and Pitboard holds back. Once for each limit, reset and reason. | **work has used 96% of its 5-hour limit.**, then a reason from [When it stays on the account](/reference/automatic-switching#when-it-stays-on-the-account) | None | Opens **Settings** on **Limits** |
| **Pitboard isn't switching Claude Code** | When Pitboard cannot decide whether to switch. Once for each reason and what it names. | A reason from [When it decides nothing](/reference/automatic-switching#when-it-decides-nothing) | None | Opens **Settings** on **Limits** |
| **Pitboard couldn't switch Claude Code** | When an automatic switch fails. Once for each kind of error. | The error | None | Opens **Settings** on **Limits** |
| **Pitboard couldn't warm up an account** | When a warm-up the app made by itself came to nothing. Once for each account and error until that account warms up. | The error | None | Opens **Settings** on **Limits** |
| **work needs signing in again** | When a read finds that an enrolled account's parked login can no longer be used: it expired, its service refused it, or none is parked. Once for each account until it can be used again, even across restarts. | **Its parked login can no longer be used, so Pitboard can't switch to it.** | **Sign In Again**, which opens **Sign In to work Again** | Opens **Accounts** |
| **A login was replaced outside Pitboard** | When a read finds that an account's only login ended outside Pitboard. A sign-in such as `/login` in Claude Code replaced it, or the account was signed out in Claude. Once for each account while reads find it, and once more after the app reopens. | The warning's message, which says what ended the login, as [Warning codes](/reference/errors#warning-codes) gives it | **Sign In Again**, which opens **Sign In to work Again** | Opens **Accounts** |

While a login file sits behind the keychain, the second sentence of **Switched Claude Code to personal** reads **Sessions already running keep the account they are on until their login is next renewed, or until they are started again:** and names the file.

The three that hold back or fail come only while **Switch Automatically** is chosen. They can come again after the app next switches. A notification starts its reason with a capital letter and ends it with a full stop.

Only **work has used 96% of its 5-hour limit** and **work needs signing in again** can have a subtitle, the tool's name once more than one tool has accounts. A button does not bring Pitboard forward unless it needs to ask something. Notifications play no sound and set no badge. macOS asks whether to allow them the first time the app posts one.

## Keyboard shortcuts

| Keys | Where | What it does |
| --- | --- | --- |
| Command-N | The menu, or any window | **Add Account** |
| Command-R | The menu, or any window | **Refresh**, **Check Again** in **This Mac**, or **Reload Page** in an account's window |
| Command-Comma | The menu, or any window | Opens Settings |
| Command-Q | The menu, or any window | **Quit Pitboard** |
| Command-C | The **Accounts** pane | Copies the email address of the account selected |
| Command-Delete | The **Accounts** pane | **Forget** the account selected, after asking |
| Return, or double-click | A row in the **Accounts** pane | What the row's button does. On the account in use when it is not enrolled, opens **Name This Account**. |
| Delete | A row in the **Accounts** pane | **Forget**, after asking |
| Return | A dialog | Its default button |
| Escape | A dialog | **Cancel**. Nothing in a Claude Desktop sign-in that has not started its wait, or has an account parked for it. |
