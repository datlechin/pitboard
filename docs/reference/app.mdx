The menu bar app calls the same core as the command line rather than running `pitboard`. It uses the same accounts, [parked logins](/concepts/switching#parked-logins) and log of changes.

The app has no Dock icon, except while a claude.ai window is open. The first time it runs, it opens the pitboard window by itself.

The app also opens a [claude.ai window](/guides/claude-web) for each enrolled Claude Code account, and the account picker for a claude.ai link from outside the app.

## Menu bar item

pitboard's item in the menu bar shows a speedometer symbol and text such as **work 42%**:

| Part | Shows |
| --- | --- |
| The label, **work** | The label of the account in use, or **unnamed** when no account in use is enrolled. A label longer than 12 characters is cut to 11 characters and an ellipsis. |
| The percentage, **42%** | How much of one limit the account has used. For Claude Code, it is the most used of the limits Anthropic marks as active, or of all its limits when none is marked. For OpenAI's Codex CLI, it is the most used limit. A limit for one model counts only when the account has no other limit. |

When both tools have accounts, the item shows one account in use: the enrolled one closest to running out. To show only the percentage or only the symbol, see [Menu bar shows](/reference/settings#menu-bar-shows).

## Menu

Clicking pitboard's item in the menu bar opens pitboard's menu. It lists what needs attention, then the accounts, then the commands.

What needs attention appears as these items:

| Item | Appears when | Choosing it |
| --- | --- | --- |
| **Switch to personal** | The account in use has used all of a limit, and `personal` has room in the same limit. The line under the item names the limit. | Switches to `personal`. |
| The title of a notice, such as **Couldn't read usage**, or **2 things to look at** when there are several | pitboard has a warning or a problem to show. | Opens the pitboard window on the **Accounts** pane, which shows each notice in full. |
| **Install pitboard** `<version>` | A copy from a release has found an update. | Opens the update window. |
| **Claude Code isn't installed** | The app found neither `claude` nor `codex`, and no tool has a login or an account. | Opens Claude Code's setup page in your browser. |

The accounts are under a heading per tool once both tools have accounts. A check mark shows the account in use in each tool. The line under each account is one of these:

| Line | Meaning |
| --- | --- |
| **5-hour 42%, weekly 12%** | How much of each limit the account has used. |
| **5-hour used up until 22:12** | The limit is used up until it resets at 22:12. A reset on a later day adds the weekday, as in **Tue 09:00**. |
| **5-hour used up** | The limit was used up when last read, and its reset time has passed since. |
| **Switching** | A switch to the account is running. |
| **Not named yet** | The tool is signed in to the account, and pitboard has not enrolled it. The item shows its email address in place of a label. |
| **Needs signing in again** | pitboard holds no parked login it can use for the account. |
| A reason that ends in `run pitboard doctor` | The item is **Login pitboard can't use**: the tool holds a login that pitboard could not read or use. |
| The email address | pitboard has no usage for the account yet. |

In place of the accounts, the menu can show one of these:

| Text | Shown when |
| --- | --- |
| **Reading accounts** | The first read has not finished. |
| **No accounts yet** | No tool is signed in and no account is enrolled. |
| **No accounts to show** | Reading failed, and pitboard has nothing earlier to show. |

Choosing an account does one of these:

| Account | Choosing it |
| --- | --- |
| An account you can switch to | Switches to it, unless a switch is running. |
| An account marked **Needs signing in again** | Opens the **Sign In to old Again** dialog in the pitboard window, where `old` is the account's label. |
| The account in use, marked **Not named yet** | Opens the **Name This Account** dialog in the pitboard window. |
| The account in use | Nothing. It stays checked. |
| An account listed as **Login pitboard can't use** | Nothing. The line under it says why pitboard cannot read or switch this login. |

The commands come last:

| Item | Shortcut | What it does |
| --- | --- | --- |
| **Add Account** | Command-N | Opens the **Add Account** dialog in the pitboard window. |
| **Refresh** | Command-R | Asks for every account's usage again, even if pitboard asked moments ago. The line under it says when usage was last read, as in **Updated 20:52**, or **Reading** during a read. **Not read yet** and **Showing the last numbers measured** mean no read has succeeded since the app opened or since your last change in the app. The second means the last read failed. |
| **Open pitboard** | Command-0 | Opens the pitboard window. |
| **Open claude.ai as work** | None | Opens the claude.ai window of `work`, the one enrolled Claude Code account. With two or more, the item is **Open claude.ai**, with a submenu of labels. Absent with none. |
| **Open claude.ai Link** | None | Opens the [account picker](#account-picker) with an empty **Link** field. Absent with no enrolled Claude Code account. |
| **Settings** | Command-Comma | Opens [Settings](/reference/settings). |
| **Check for Updates** | None | Opens the update window. Only in a copy from a release. |
| **About pitboard** | None | Shows the app's version. |
| **pitboard Help** | None | Opens this site in your browser. |
| **Quit pitboard** | Command-Q | Quits the app. |

## Window

The pitboard window has three panes, listed in its sidebar: **Accounts**, **Activity** and **This Mac**.

### Accounts pane

The **Accounts** pane lists notices about what needs attention, then at most one tip for setting up, then the accounts. Its toolbar has **Refresh** (a circular arrow, Command-R) and **Add Account** (a plus sign).

When there is nothing to list, the pane shows one of these instead:

| Title | Shown when | Button |
| --- | --- | --- |
| **Claude Code Isn't Installed** | The app found neither `claude` nor `codex`, and no tool has a login or an account. | **How to Install Claude Code** |
| **Couldn't Read Accounts** | A read failed and there is no account to list. The reason is under the title. | **Try Again** |
| **No Accounts** | No tool is signed in and no account is enrolled. | **Add Account** |

A tip suggests the next step in setting up pitboard:

| Tip | Shown when | Buttons |
| --- | --- | --- |
| **Give this account a name** | A tool is signed in to an account pitboard has not enrolled. | **Name** opens **Name This Account**. |
| **Add a second account** | A tool has one enrolled account, and it is the one in use. When both tools have accounts, the title names the tool, as in **Add a second Codex account**. | **Add Account**, or **Not Now** to stop showing the tip for that tool. |

Each account's row has these parts:

| Part | Shows |
| --- | --- |
| Name | A symbol, the account's label and its email address. |
| Right side | **In Use**, or a button: **Use** or **Sign In Again**. |
| A line per limit | The limit's short name, such as **5h** or **week**, then a bar and the percentage used. Last is the time to its reset, such as **in 2h 10m**. The bar is green under 70%, orange from 70% and red from 90%. |
| Notes | In this order: why the account cannot be used, why its numbers are old, how long it lasts at the rate it has been used and how long its parked login lasts. The last appears only for a Claude Code account not in use. |

For what each line means, see [Check what each account has left](/guides/usage#read-the-lines-under-each-account).

Notices say what needs attention, most pressing first:

| Notice | Shown when | Buttons |
| --- | --- | --- |
| **An interrupted switch is waiting** | A switch stopped partway, and pitboard cannot yet tell whether it finished. | **Give Up** |
| **Couldn't read usage** | The last read failed. The reason is under the title. | None |
| **work has no 5-hour limit left** | The account in use has used all of a limit, and another account has room. | **Switch to personal** |
| **Switched to work** | A switch you made in the app finished. The lines under it say what happens to open sessions. | **Dismiss** (an x) |
| **work has a new login** | A sign-in in the app gave the account in use a new login. | **Dismiss** (an x) |
| The title of another warning, such as **A parked login was refused** | A read or a change gave a warning. For each title, see [Warning codes](/reference/errors#warning-codes). | None |
| **Gave up on the interrupted switch** | You clicked **Give Up** and confirmed. | **Dismiss** (an x) |

### Activity pane

The **Activity** pane lists the last 500 changes pitboard made, newest first, from the app and the command line. **Refresh** (Command-R) reads the log again.

| Column | Shows |
| --- | --- |
| **Date** | When the change was made. |
| **Change** | What was done, such as **Use** for a switch, **Enrol**, **Rename**, **Forget** or **Renew**. |
| **Account** | What the change was about, as [`pitboard log`](/reference/maintenance-commands#log) records it. For most changes it is a label, such as `work` or `codex/work`. |
| **Result** | **Done**, or the outcome's code written out in words, such as **Renewed** or **Parked login refused**. |
| **Asked By** | **pitboard app**, **Command line**, or **Unknown** for a change logged before pitboard recorded who asked. |

### This Mac pane

The **This Mac** pane runs the same checks as [`pitboard doctor`](/reference/maintenance-commands#doctor) each time you open it. Each check shows a green, orange or red symbol, what it found and, if it did not pass, what to do. **Check Again** (Command-R) runs them again.

## Account actions

Control-click an account in the **Accounts** pane to open its shortcut menu. For an account labelled `work`, it shows these items, in this order, where they apply:

| Item | Shown for | What it does |
| --- | --- | --- |
| **Use work** | An account you can switch to | Switches to it. |
| **Name** | The account in use, when it has no label | Opens **Name This Account**. |
| **Open claude.ai** | An enrolled Claude Code account | Opens its claude.ai window. |
| **Sign In Again** | Any enrolled account, including the one in use | Opens **Sign In to work Again**. |
| **Rename** | Any enrolled account | Opens **Rename "work"**. |
| **Copy Email Address** | Any account with an email address | Copies the address. |
| **Forget** | An enrolled account that is not in use | Asks, then forgets the account. |

Double-clicking a row, or selecting it and pressing Return, does what its button does. On the account in use that has no label, it opens **Name This Account**. Pressing Delete asks to forget the selected account.

| Dialog | Opened by | Contents |
| --- | --- | --- |
| **Add Account** | **Add Account** in the menu, the toolbar or a tip; Command-N | A **Tool** pop-up menu when more than one tool is offered, a **Name** field and **Sign In**. Under the form, a line names a tool that is not offered, such as **Codex is not offered: pitboard did not find codex on this Mac.** |

The same dialog takes this title. | **Waiting for your browser** while you sign in there. **Browser didn't open?** with **Open Sign-In Page**, when the tool gives its sign-in address. If an action fails, the dialog stays open with what you entered. It shows the reason under a title such as **Couldn't sign in to work**.

| Alert | Opened by | Says | Buttons |
| --- | --- | --- | --- |
| **Forget "work"?** | **Forget** in a shortcut menu, or pressing Delete on a selected row | For a Codex account: **pitboard deletes the login it parked for this account. Using it again needs a sign-in in your browser.** For a Claude Code account: **pitboard deletes the login it parked for this account, and everything its claude.ai window keeps on this Mac, its sign-in included. Using it again needs a sign-in in your browser.** | **Forget**, **Cancel** |

## claude.ai windows

Each enrolled Claude Code account has at most one [claude.ai window](/guides/claude-web). Its title is the account's label, and its subtitle is the page's title, or **claude.ai** before a page has loaded. A window closed and opened again starts at claude.ai's home page.

In place of the page, the window shows **Reading accounts** until the app has read the accounts, and **Opening claude.ai** while it sets up the page. It shows **Signing out** during a sign-out. A window whose account is no longer enrolled closes itself.

While a claude.ai window is open, the app has a Dock icon, is in the Command-Tab switcher and shows its menus in the menu bar.

The toolbar has **Back** and **Forward**, dimmed when there is nowhere to go, and **Reload** (a circular arrow). The **View** menu has the same commands with their shortcuts. A two-finger swipe goes back or forward, and pinching zooms.

A bar at the top of the window says what pitboard has to say about it. The next message replaces it, and **Dismiss** (an x) closes it:

| Text | Shown when | Button |
| --- | --- | --- |
| **Sign in to claude.ai as** `<email>`, with how to use **Continue with email**: tap the emailed link on your phone, then enter here the code claude.ai shows there | The window opens on data WebKit had not stored before: the first time, and after **Sign Out of This Window** | None |
| **Google does not allow its pages inside apps, so pitboard stopped it.**, with how to sign in by email, and that Gmail, Google Drive, Google Calendar and Google single sign-on cannot be connected in the window | The page went to Google's sign-in | None |
| **claude.ai opened a page in your browser.**, and that anything connected there goes to the claude.ai account the browser is signed in to | claude.ai sent a page to the browser without a click | None |
| **claude.ai tried to open a window pitboard doesn't show.** | claude.ai asked for a window with no address, or with a `blob:` or `data:` link that is not a download | None |
| **claude.ai didn't load:**, the reason, and **Click Reload to try again.** | A page did not load, or the page's process ended twice before one finished loading | None |
| **Downloading "report.pdf"** | A download started | None; a spinner |
| **Downloaded "report.pdf" to Downloads.** | A download finished | **Show in Finder** |
| **Couldn't download "report.pdf":** and the reason | A download failed | None |

The window stays on `https://claude.ai`. A link to anywhere else opens in your default browser, and an email address you click opens in your default email app. A claude.ai link asked for in a new window opens in this one.

The window refuses the microphone and the camera, and shows no web notifications. A page's alert or confirmation appears as a dialog over the window, titled with the site that asked. WebKit's own **Download Linked File**, **Download Image** and **Download Video** are left out of the shortcut menu.

A download from claude.ai's own page goes straight to Downloads. One that an artifact, another frame or another site starts asks first. Closing the window lets a download finish; **Sign Out of This Window** and forgetting the account stop it. Each download is quarantined, as a browser's is.

These menu commands act on the claude.ai window in front, and are dimmed when no claude.ai window is:

| Command | Menu | Shortcut | What it does |
| --- | --- | --- | --- |
| **Open Link** | **File** | Command-L | Opens the dialog **Open a claude.ai Link as work**, with a **Link** field. **Open** stays dimmed until the field holds a claude.ai link, and a line under a refused link says why. |
| **Sign Out of This Window** | **File** | None | Asks, then stops the window's downloads, deletes everything the window keeps and opens claude.ai again, signed out. |
| **Reload Page** | **View** | Command-R | Loads the page again. |
| **Back**, **Forward** | **View** | Command-Left Bracket, Command-Right Bracket | Shows the previous or next page, dimmed when there is none. |
| **Actual Size**, **Zoom In**, **Zoom Out** | **View** | Command-0, Command-Plus, Command-Minus | Sets the page's zoom through Safari's steps, from 50% to 300%, for the life of the window. |

The **File** menu also has **Open claude.ai as work**, or **Open claude.ai** with a submenu, as pitboard's menu does.

| Alert | Says | Buttons |
| --- | --- | --- |
| **Sign out of claude.ai in this window?** | **pitboard deletes this window's sign-in and everything else claude.ai keeps for "work" on this Mac. The account stays signed in on your other devices and browsers. claude.ai's own Log Out would sign it out on every device.** | **Sign Out**, **Cancel** |
| **Couldn't sign out of this window** | WebKit's reason. The window opens again, still signed in. | **OK** |
| **Download "report.csv" from www.claudeusercontent.com?** | **pitboard saves it to your Downloads folder.** Shown for a download that an artifact, another frame or another site starts. | **Download**, **Cancel** |

## Account picker

The account picker, a small window titled **Open claude.ai Link**, asks which account's claude.ai window opens a link. Nothing opens until you choose an account and click **Open**, even with one account.

It opens for **Open claude.ai Link** in pitboard's menu, a `pitboard://` link, **Open in pitboard** in the Services menu and **pitboard** in the Share menu. For each of them, see [Open claude.ai links as an account](/guides/claude-links). A second link while the picker is open replaces the first and keeps your choice.

| Title | Shown when | Buttons |
| --- | --- | --- |
| **Open claude.ai Link**, with the link and the accounts | A claude.ai link, and at least one enrolled Claude Code account | **Cancel**, **Open** |
| **Open claude.ai Link**, with a **Link** field and the accounts | You chose **Open claude.ai Link** in pitboard's menu. **Open** stays dimmed until the field holds a claude.ai link, and a line under a refused link says why. | **Cancel**, **Open** |
| **Open claude.ai Link**, with **Reading accounts** | The app has not read the accounts yet | **Cancel** |
| **Couldn't Read Accounts**, with the reason | The first read failed | **Cancel** |
| **No Account Has a claude.ai Window** | No enrolled Claude Code account | **Cancel**, **Open in Browser**, **Add Account** |
| **No Account Has a claude.ai Window**, naming the login's email address | No enrolled Claude Code account, and a Claude Code login with no name in pitboard | **Cancel**, **Open in Browser**, **Name** |
| **Can't Open This Link**, with the reason | The link is refused | **OK** |

**Open in Browser** opens the link in your default browser. **Add Account** and **Name** open the dialogs of those names in the pitboard window.

Each account shows its label and email address. An account whose window is open adds **Window open. The link replaces what it shows; Back returns.** The picker first selects the account you chose last since the app opened, then the Claude Code account in use, then the first.

### Refused links

The account picker, the **Open Link** dialog and the Share extension refuse the same links in the same words:

| Link | Says |
| --- | --- |
| On another site or a subdomain of claude.ai | **pitboard opens claude.ai links only. This link is on example.com.** |
| On claude.ai with a port, such as `claude.ai:8443` | **pitboard opens claude.ai links only. This link is on claude.ai:8443.** |
| With a user name before the host | **pitboard opens claude.ai links only.** |
| claude.ai's emailed sign-in link, under `/magic-link`, however its path is written | **pitboard doesn't open claude.ai sign-in links from outside: one would sign the window in as whoever the link belongs to. Sign in inside the account's claude.ai window.** |
| A path with a `.` or `..` segment, which claude.ai's own links never have | **There is no claude.ai link in what was sent.** |
| Anything that is not an `http` or `https` link, such as `javascript:` or `file:` | **There is no claude.ai link in what was sent.** |
| Longer than 8192 characters | **What was sent is too long to be a claude.ai link.** |
| A `pitboard://` link asking for something this version does not know | **This pitboard link isn't one this version knows.**, and to update pitboard or paste the link into **Open claude.ai Link** |
| A `pitboard://` link with more in it than one encoded link | **This pitboard link has more in it than one claude.ai link. The link inside it has to be encoded, as the bookmarklet does.** |

pitboard takes `http://claude.ai` as `https`, and a bare `claude.ai/chat/abc` as `https://claude.ai/chat/abc`.

### The pitboard link

A pitboard link is `pitboard://open?url=` followed by one claude.ai link, encoded as JavaScript's `encodeURIComponent` encodes it:

```text
pitboard://open?url=https%3A%2F%2Fclaude.ai%2Fpublic%2Fartifacts%2F0e5a
```

`open` is the only request. A link with a fragment, a second item or no `url` is refused.

## Services and Share menus

| Item | Where | What it does |
| --- | --- | --- |
| **Open in pitboard** | The **Services** menu of any app, and the shortcut menu of a selection, when the selection holds a link | Takes the link the app sent, or the first claude.ai link in the first 64 KB of the selected text, and opens the account picker for it. It has no shortcut until you give it one in **System Settings** > **Keyboard** > **Keyboard Shortcuts** > **Services**. |
| **pitboard** | The Share menu | Opens the account picker for the page being shared. A page not on claude.ai is refused in the Share extension's own dialog, **Can't Open This Link**, with **OK**, and nothing reaches pitboard. If macOS cannot open pitboard, the dialog is **Couldn't Open pitboard**, with the reason. |

The Share extension is sandboxed: it has no network or file access and keeps nothing.
