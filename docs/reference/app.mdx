The app calls the same core as the command line, not `pitboard`, so both see the same accounts, [parked logins](/concepts/switching#parked-logins) and log.

While any of its windows is open, Pitboard also has a Dock icon, a place in the Command-Tab switcher and [its own menus](#app-menus). Its windows are the Pitboard window, Settings, each [account's window](/reference/account-windows#account-windows) and the [**Open Link** window](/reference/account-windows#open-link-window).

The first time the app runs, it opens the Pitboard window.

## Menu bar item

Pitboard's item in the menu bar shows a speedometer symbol, the account in use and how much of one limit it has used, such as **work 42%**. [Menu bar shows](/reference/settings#menu-bar-shows) can leave out the label, or the label and the percentage.

| Part | Rule |
| --- | --- |
| Label | The label of the account in use, or **unnamed** when it is not enrolled. Past 12 characters, it is cut to 11 and an ellipsis. |
| Percentage | The fullest limit, as a whole percentage. A limit for one model counts only when there is no other. When Anthropic marks some limits active, only those count. |
| With both tools | The enrolled account in use closest to running out. A tie goes to Claude Code. |

Before the first read, and while no tool is signed in, the item shows the symbol alone. Until the account has a reading, it shows the label alone.

## Menu

Clicking Pitboard's item opens its menu: what needs attention, then the accounts, then the commands.

What needs attention, in this order:

| Item | Line under it | Shown when | Choosing it |
| --- | --- | --- | --- |
| **Claude Code isn't installed** | **Learn how to install it** | The app found neither `claude` nor `codex`, and no tool has a login or an account. | Opens Claude Code's setup page. |
| **Switch to personal** | The notice's title | The account in use ran out of a limit, and `personal` has room. | Switches to `personal`. |
| The notice's title, such as **Couldn't read usage**, or **2 things to look at** for several | **Show in Pitboard**, or the first notice's title | The [Accounts pane](#accounts-pane) has a notice with an orange or red symbol and no switch button. | Opens the **Accounts** pane. |
| **Install Pitboard 0.10.1** | None | A copy from a release found an update. | Opens the update window. |

Once both tools have accounts, each tool has its own heading. A check mark shows the account in use in each tool. An account shows its label, its email address while it has none, or **Login Pitboard can't use**. [Read the lines under each account](/guides/usage#read-the-lines-under-each-account) explains the line under it.

Instead of accounts, the menu can show:

| Text | Shown when |
| --- | --- |
| **Reading accounts** | The first read has not finished. |
| **No accounts yet** | No tool is signed in and no account is enrolled. |
| **No accounts to show** | Reading failed, with nothing earlier to show. |

Choosing an account:

| Choosing | Does |
| --- | --- |
| An account you can switch to | Switches to it. |
| An account marked **Needs signing in again** | Opens **Sign In to work Again**. Dimmed while a sign-in runs. |
| The account in use, marked **Not named yet** | Opens **Name This Account**. |
| The account in use, when enrolled, or **Login Pitboard can't use** | Nothing. |

While a switch runs, **Switch to personal** and every account but the one in use are dimmed.

The commands, in this order:

| Item | Shortcut | What it does |
| --- | --- | --- |
| **Add Account** | Command-N | Opens **Add Account**. |
| **Refresh** | Command-R | Reads every account's usage again, even one read moments ago. Dimmed during a read. |
| **Open claude.ai as work** | None | Opens the window of `work`, the only Claude Code account. With several, **Open claude.ai** has a submenu. |
| **Open chatgpt.com as main** | None | The same, for Codex accounts. |
| **Open Pitboard** | Command-0 | Opens the Pitboard window. |
| **Settings** | Command-Comma | Opens [Settings](/reference/settings). |
| **Check for Updates** | None | Opens the update window. Only in a copy from a release. |
| **About Pitboard** | None | Shows the app's version. |
| **Pitboard Help** | None | Opens this site. |
| **Quit Pitboard** | Command-Q | Quits the app. |

The line under **Refresh**:

| Line | Means |
| --- | --- |
| **Updated 20:52** | When the last read finished, with the weekday on another day. |
| **Reading** | A read is running. |
| **Not read yet** | No read has finished since the app opened or your last change. |
| **Showing the last numbers measured** | The same, after a failed read. |

## Window

The Pitboard window's sidebar holds three panes: **Accounts**, **Activity** and **This Mac**. It opens on the pane you last showed.

### Accounts pane

The **Accounts** pane lists notices, then at most one setup tip, then the accounts by tool. The window's subtitle reads **Updated 20:52**, or **Reading** during a read. The toolbar has **Refresh** and **Add Account**.

Instead of the list, the pane can show:

| Shows | When | Button |
| --- | --- | --- |
| **Claude Code Isn't Installed** | Same as the menu's **Claude Code isn't installed**. | **How to Install Claude Code** |
| **Couldn't Read Accounts** and the reason | A read failed, with no account to list. | **Try Again**, dimmed during a read |
| **No Accounts** | No tool is signed in and no account is enrolled. | **Add Account** |
| **Reading accounts** | The first read has not finished. | None |

| Setup tip | Shown when | Buttons |
| --- | --- | --- |
| **Give this account a name** | A tool is signed in to an account Pitboard has not enrolled. | **Name**, which opens **Name This Account** |
| **Add a second account**, or **Add a second Codex account** with both tools | A tool's only enrolled account is the one in use. | **Add Account**, set to that tool. **Not Now** stops the tip for that tool. |

| Part of a row | Shows |
| --- | --- |
| Name | A symbol, the label and the email address, or the email address alone while there is no label. |
| Right side | **In Use**, a progress indicator while a switch to it runs, or a button: **Use** or **Sign In Again**. |
| A line per limit | Its short name, such as **5h** or **week**, a bar, the percentage, when it resets, as **resets in 2h 10m**, and its pace, as **27% over pace**. |
| Notes | In order: why it cannot be used, why its numbers are old, which limit runs out first, and how long its parked login lasts. The third shows only on the account in use. |

A bar's tooltip says what an even pace would have used so far. [Read the lines under each account](/guides/usage#read-the-lines-under-each-account) explains each part.

Notices, most pressing first:

| Notice | Shown when | Buttons |
| --- | --- | --- |
| **An interrupted switch is waiting** | A switch stopped partway, and Pitboard cannot yet tell whether it finished. | **Give Up**, which asks first |
| **Couldn't read usage** | The last read failed, for the reason under the title. | None |
| **work has no 5-hour limit left** | The account in use ran out of a limit, and another account of its tool has room. With both tools, the tool's name comes first. | **Switch to personal** |
| **Switched to work**, or **Switched Codex to work** with both tools | A switch the app made finished, asked for or automatic. Its lines say what happens to open sessions, with a countdown for Claude Code. | **Dismiss** (an x) |
| **work has a new login**, or **work in Codex has a new login** with both tools | A sign-in in the app gave the account in use a new login. | **Dismiss** (an x) |
| **Claude Code's config names another account** | The config names another account than the one whose login Claude Code has stored. | **Update Claude Code's Config**, while the account in use is enrolled. It writes that account into the config and moves no login. It fails if another login is stored by then. |
| **A login file is left behind the keychain** | `~/.claude/.credentials.json` sits behind the keychain. | **Put Away**. None when Pitboard cannot read the file. |
| Another warning's title, such as **A parked login was refused** | A read or a change warned. [Warning codes](/reference/errors#warning-codes) lists each title. | None |
| **Gave up on the interrupted switch** | You gave up on it. | **Dismiss** (an x) |
| **Put away the login left in a file** | **Put Away** finished. Its lines say what became of the login and the file's other keys. | **Dismiss** (an x) |

### Activity pane

The **Activity** pane lists the last 500 changes in Pitboard's log, newest first, from the app and the command line. With nothing logged, it shows **No Activity**.

| Column | Shows |
| --- | --- |
| **Date** | When, in your Mac's date and time format. |
| **Change** | The verb [`pitboard log`](/reference/maintenance-commands#log) records, named as in the next table. |
| **Account** | The subject the log records, such as `codex/work` or `wrong -> right`. |
| **Result** | **Done**, or the outcome's code in words, such as **Parked login expired** for `parked_login_expired`. |
| **Asked By** | **Pitboard app**, **Command line**, or **Unknown** for a change logged before Pitboard recorded who asked. |

| Change | Verb |
| --- | --- |
| **Switch** | `use` |
| **Automatic switch** | `auto-switch` |
| **Automatic switch not made** | `auto-stay` |
| **Enrol** | `enroll` |
| **Login in use changed** | `in-use` |
| **Put away a login left in a file** | `stow` |
| **Give up on a switch** | `abandon` |

Any other verb starts with a capital letter, as `rename` reads **Rename**.

### This Mac pane

The **This Mac** pane runs the checks of [`pitboard doctor`](/reference/maintenance-commands#doctor) each time you show it. It shows **Checking this Mac** until the first ones finish. Over them, doctor's summary line, such as **One thing is worth looking at.**, sits beside **Checked at 14:05**.

Each check shows a green, orange or red symbol, its name, what it found and, when it did not pass, what to do. **Check Again** runs them again.

## Account actions

Control-clicking an account in the **Accounts** pane opens its shortcut menu. For `work`, it lists, in order:

| Item | Shown for | What it does |
| --- | --- | --- |
| **Use work** | An account you can switch to, while no switch runs | Switches to it. |
| **Name** | The account in use, when it is not enrolled | Opens **Name This Account**. |
| **Sign In Again** | Every enrolled account, the one in use too | Opens **Sign In to work Again**. Dimmed while a sign-in runs. |
| **Rename** | Every enrolled account | Opens **Rename "work"**. |
| **Open claude.ai** or **Open chatgpt.com** | Every enrolled account | Opens the account's [window](/reference/account-windows#account-windows). |
| **Copy Email Address** | Every account with an email address | Copies it. |
| **Forget** | An enrolled account not in use | Asks, then forgets the account. |

## Dialogs and alerts

Dialogs open over the Pitboard window's **Accounts** pane.

| Dialog | Opened by | Holds |
| --- | --- | --- |
| **Add Account** | **Add Account** in a menu, the toolbar or a tip | A **Tool** pop-up menu when more than one tool is offered, a **Name** field and **Sign In**. A line under them names a tool not offered, as in **Codex is not offered: Pitboard did not find codex on this Mac.** |
| **Sign In to work Again** | **Sign In Again**, or an account marked **Needs signing in again** in the menu | The account's label and **Sign In**. |
| **Signing In to Claude Code** or **Signing In to Codex** | **Sign In** | **Waiting for your browser**, and **Open Sign-In Page** beside **Browser didn't open?** once the tool gives its address. For Claude Code, a **Code** field and **Submit Code** once it asks for one. **Cancel** stops the sign-in. |
| **Name This Account** | **Name**, or an account marked **Not named yet** in the menu | A **Name** field and **Save**. |
| **Rename "work"** | **Rename** | A **Name** field holding the label, and **Rename**. |
| **Put Away the Login Left in a File** | **Put Away** on its notice | **Finding out whose login it is**, then what the file holds and what putting it away does, as [`pitboard stow`](/reference/recovery-commands#stow) says it. **Put Away** is dimmed for a login of an account not enrolled, and when nothing is left. |

**Add Account** offers each tool whose program the app found or that has an account. With neither, it offers Claude Code alone.

If Claude Code refuses a code, the dialog says **Claude Code didn't take that code. Copy the whole code your browser shows, and paste it again.** and shows the **Code** field again.

If an action fails, its dialog stays open with what you entered and says why under one of these titles:

- **Couldn't sign in to work**
- **Couldn't name this account**
- **Couldn't rename work**
- **Couldn't tell whose login it is**
- **Couldn't put the login away**. The dialog then reads the file again.

| Alert | Opened by | Says | Buttons |
| --- | --- | --- | --- |
| **Forget "work"?**, or **Forget "work (Codex)"?** with both tools | **Forget**, or Delete on a selected row | **Pitboard deletes the login it parked for this account, and everything its claude.ai window keeps on this Mac, its sign-in included. Using it again needs a sign-in in your browser.** For a Codex account, it names the chatgpt.com window. | **Forget**, **Cancel** |
| **Give up on the interrupted switch?** | **Give Up** | **Every login is kept, and nothing is deleted. Pitboard stops trying to finish it.** | **Give Up**, **Cancel** |
| **Quit ChatGPT to switch?** | A switch to a Codex account while the ChatGPT app is open | **ChatGPT keeps using the account it started with until it quits. Pitboard quits it, switches, and opens it again.** | **Quit ChatGPT and Switch**, **Cancel** |
| **Couldn't switch to work**, **Couldn't forget work**, **Couldn't give up on the interrupted switch** or **Couldn't update Claude Code's config** | That action failed, wherever it started | The reason, then any warnings | **OK** |

A failure alert opens the Pitboard window.

Account windows' alerts are in [Account windows and shared links](/reference/account-windows).

## App menus

| Menu | Item | Shortcut | What it does |
| --- | --- | --- | --- |
| **File** | **Add Account** | Command-N | Opens **Add Account**. |
| **File** | **Open claude.ai as work**, **Open chatgpt.com as main**, or a submenu for a site with several accounts | None | Opens that account's window. |
| **File** | **Remove Website Data** | None | Asks, then [removes the website data](/reference/account-windows#remove-website-data) of the account window in front. Dimmed unless one is in front. |
| **Edit** > **Find** | **Find**, **Find Next**, **Find Previous**, **Use Selection for Find** | Command-F, Command-G, Shift-Command-G, Command-E | Finds text in the page of the account window in front. |
| **View** | **Refresh**, **Check Again** or **Reload Page** | Command-R | The button of the window in front: **Check Again** in **This Mac**, **Reload Page** in an account's window, **Refresh** in the other panes. Dimmed elsewhere, and while it runs. |
| **View** | **Actual Size**, **Zoom In**, **Zoom Out** | Command-0, Command-Plus, Command-Minus | Zooms the page in the account window in front. |
| **Go** | **Back**, **Forward** | Command-Left Bracket, Command-Right Bracket | Shows the previous or next page in the account window in front. |
| **Help** | **Pitboard Help** | None | Opens this site. |

### Dock menu

The Dock icon's menu lists the items that open account windows, as the **File** menu does, then **Open Pitboard**. macOS adds the open windows.

Opening Pitboard from Finder or Spotlight with no window open opens the Pitboard window.

## Notifications

| Title | Posted | Body | Button |
| --- | --- | --- | --- |
| **work has no 5-hour limit left** | When the account in use runs out of a limit and another account of its tool has room, as [When an account runs out](/guides/switch#when-an-account-runs-out) says. Once for each limit and reset, even across restarts. | **personal has 58% of its own left.**, or **seat has no such limit.** for an account without that limit | **Switch**, which switches to `personal` |
| **Switched Claude Code to personal** | After each switch the app makes by itself. | **work had used 96% of its 5-hour limit. Sessions already running follow within 33 seconds.** | None |
| **Claude Code was not switched** | When a limit of the account in use reaches the share in **Switch when a limit reaches**, and Pitboard holds back. Once for each limit, reset and reason. | **work has used 96% of its 5-hour limit.**, then a reason from the first list that follows | None |
| **Pitboard is not switching Claude Code** | When Pitboard cannot decide whether to switch. Once for each reason and what it names. | A reason from the second list | None |
| **Pitboard could not switch Claude Code** | When an automatic switch fails. Once for each kind of error. | The error | None |
| **A login was replaced outside Pitboard** | When a read finds that a sign-in outside Pitboard, such as `/login` in Claude Code, replaced an account's only login. Once for each account while reads find it, and once more after the app reopens. | The warning's message, which names the login stored in its place and ends **Run `pitboard enroll work --sign-in` to sign in to it again.** | None |

While a login file sits behind the keychain, the second sentence of **Switched Claude Code to personal** reads **Sessions already running keep the account they are on until their login is next renewed, or until they are started again:** and names the file.

The three that hold back or fail come only while **Switch Claude Code automatically** is on. They can come again after the app next switches. [When it holds back](/guides/automatic-switching#when-it-holds-back) says what each reason means and when it ends.

Only the run-out notification has a subtitle: **Claude Code** or **Codex**, with both tools. Clicking a notification itself does nothing. Notifications play no sound and set no badge. macOS asks whether to allow them the first time the app posts one.

**Claude Code was not switched** ends with one of these reasons:

- **No other Claude Code account has room below 95% in every limit.**
- **No other Claude Code account has room below 95% in every limit, and there is no reading of personal from Anthropic yet.**
- **This limit was switched away from once already, and is not again before it resets.**
- **3 attempts to switch away from this limit failed, and none is made again before it resets.**
- **The account was put in use less than 5 minutes ago.**
- **Claude Code signs in another way, set by** `apiKeyHelper in /Users/me/.claude/settings.json`**, so a switch would change nothing its sessions use.**

**Pitboard is not switching Claude Code** gives one of these:

- **A switch was interrupted, and the next change you make finishes it.**
- **Claude Code uses a custom OAuth endpoint, and Pitboard does not act on Claude Code then.**
- **Claude Code has no login stored.**
- **Claude Code has me@example.com's login stored, and that account is not enrolled.**
- **Whose login Claude Code has stored could not be told (could not reach Anthropic).**
- **There is no reading of work from Anthropic yet.**

## Keyboard shortcuts

Keys that no menu shows:

| Keys | Where | What it does |
| --- | --- | --- |
| Return, or double-click | A row in the **Accounts** pane | What the row's button does. On the account in use when it is not enrolled, opens **Name This Account**. |
| Delete | A row in the **Accounts** pane | **Forget**, after asking |
| Return | A dialog | Its default button: **Sign In**, **Submit Code**, **Save**, **Rename** or **Put Away** |
| Escape | A dialog | **Cancel** |
